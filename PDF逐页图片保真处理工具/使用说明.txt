PDF逐页图片保真处理工具
========================

一、输出结构

假设输入文件是：
    美文 少年散文.pdf

程序会在PDF旁边创建：
    美文 少年散文/001.png、002.png、003.png……
    美文 少年散文-processed/001.png、002.png、003.png……

页数超过999时会自动使用四位编号，例如0001.png，保证文件排序正确。


二、首次安装

需要Python 3.10或更新版本。

Windows：
    1. 安装Python，并在安装时勾选“Add Python to PATH”。
    2. 在本工具文件夹打开终端，运行：
       py -3 -m pip install -r requirements.txt

macOS：
    1. 安装Python 3。
    2. 在终端进入本工具文件夹，运行：
       python3 -m pip install -r requirements.txt


三、运行

最简单的方法：
    Windows双击“run-windows.bat”，把一个或多个PDF拖入命令窗口，然后按回车。
    也可以同时选中多个PDF并拖到“run-windows.bat”图标上。
    该启动器内部只使用ASCII字符和Windows CRLF换行，避免中文代码页破坏命令。
    macOS双击“macOS-运行.command”，把一个或多个PDF拖入终端窗口，然后按回车。

Windows启动器会检查Python和依赖；首次运行缺少依赖时会自动安装。
如果失败，窗口会保留并显示具体错误，不会直接退出。

每批文件全部处理完后，程序会回到常驻等待界面，可继续拖入下一批文件，不会自动退出。
在等待界面直接按回车，可以打开文件多选窗口；取消多选窗口只会返回等待界面，不会退出。
只有输入Q并按回车才会退出程序。

也可以使用命令行：
    python pdf_image_processor.py "D:\扫描\书名.pdf"
    python3 pdf_image_processor.py "/Users/name/Scans/书名.pdf"
    python pdf_image_processor.py "第一本.pdf" "第二本.pdf"

命令行如需只处理一次并立即退出，可增加：
    --once


四、处理模式

默认strong模式。对原图为灰度的页面，输出仍是单通道灰度PNG，不会凭空产生黄色/蓝色彩噪；文字和表格线按连通结构保护。程序还会检测相对于纸张背景更暗的细长笔画，保护没有黑色核心的浅铅笔字和手写线条。

程序会同时检测彩色和黑白照片。识别为照片后，将保护完整的照片矩形；照片内部的天空、墙面、纸张等平坦背景也保持原始像素，不作为页面底色清除。与图像外边界相连且被明确识别为扫描台灰边、黑边的区域除外，边框清理的优先级高于照片保护。

程序会从图像四条物理边界向内检测与边界连续的扫描台灰带、黑边和分界线，并将它们改为白色；不会裁剪或改变图片尺寸，也不会把页面内部的灰色图形当作边框。

更保守清理：
    python pdf_image_processor.py "书名.pdf" --mode safe --overwrite

strong模式会清理更深的灰底和黄斑；连续的大块灰色图形会作为整体保护。自动判断仍不可能绝对正确，请先在代表性页面上抽查。


五、断点续跑和覆盖

默认情况下，已经存在、能够正常打开且由当前算法版本生成的PNG会被跳过。因此处理中断后，重新运行即可继续。程序更新后，旧算法生成的处理图会自动重新生成，不会错误沿用。

如需用新参数重新生成全部图片，增加：
    --overwrite


六、保真原则

1. 程序不使用生成式AI，不补字、不重画笔画。
2. 优先直接提取PDF中的整页扫描图；复杂页面才按300 dpi渲染。
3. 原始逐页图片永久放在“原名”文件夹中。
4. 处理后的图片放在“原名-processed”文件夹中。
5. 输出PNG为无损格式，并保留300 dpi标记。
6. 深色文字、表格线、彩色区域、图像、连续的大块灰色图形以及浅色手写笔画会先设为保护区域。
7. 自动处理无法百分之百区分污渍与非常浅的真实图形，整本导入DCP前必须抽查。


七、建议抽查页面

封面、纯文字页、照片页、黄色插图、灰色图形、手写页、污渍最重页、黑边最宽页。
